TENIR-Gov

A runtime governor from TENIR Labs. It admits each agent action before the call leaves the agent; Magertron™ then governs and records the call.

What it adds

  • Admitted by a runtime governor before the call leaves the agent
  • Executed exactly once under that admission
  • Correlated evidence on both sides
  • If the governor says no, nothing reaches Magertron™

How it connects

  • TENIR-Gov runs beside the agent and keeps its own state
  • Each admitted call carries its mission and attempt ids as two request headers
  • Magertron™ writes both ids to the call's audit row, next to the agent and the person it acts for
  • Agent and person identities come from the customer's identity provider, joined by the Magertron™ token service
“From ‘the agent was allowed to call’ to ‘the agent was allowed to act, once, under a verified mandate, and both systems recorded it.’”TENIR Labs
