How it works

Four commands. An agentic experience in minutes.

Czartup™ keeps the whole app in one short document, the Czarter. Every command reads it, so the IDE, the terminal and the Magertron™ console always agree.

/czartup-new

Describe it

Say what the app does, who uses it, its limits and approvals. Czartup drafts the Czarter and saves nothing until you agree.

/czartup-setup

Set it up

A preview of every change, then one yes: the IdP app with MFA, the agent's identity, people, policy and grants.

/czartup-build

Build it

Your coding assistant builds the servers and the app from Czartup's hand-over pack, then stops for the administrator.

/czartup-verify

Prove it

Live checks against the platform: limits refuse, holds wait, the agent reaches only its own tools. Run it in CI too.

Also: /czartup-approvals builds the app's approvals screen, /czartup-update follows a changed Czarter, /czartup-status says what's next, and /czartup-retire removes an app cleanly.

Get started

Connect, sign in, describe.

Czartup™ runs inside your Magertron™ AI Orchestrator. Your IDE reaches it as an MCP server; the CLI adds the slash commands and does the same work from a terminal.

1. Connect Czartup to your IDE

Add Czartup™ as an MCP server, with its address and nothing else, then click Authenticate and sign in to Magertron™ with your own account and MFA. Use the address you open the Magertron console or developer portal at.

"czartup": { "url": "https://your-magertron/mcp/mcp-prod/czartup/" }

2. Add the slash commands

Install the CLI, sign in, and add the /czartup-... commands to Cursor, Claude Code and Codex. On Debian or Ubuntu it installs with apt.

curl -fsSL https://magertron.com/install-czartup.sh | sh czartup login https://your-magertron czartup commands

3. Describe your first app

Open an empty folder in your IDE and type /czartup-new followed by what the app does, who uses it, and its limits and approvals.

/czartup-new Use Czartup to build ... on Magertron, in the namespace ...
