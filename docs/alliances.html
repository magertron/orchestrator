Alliance Program

Magertron governs what AI agents can reach — which tools, which data, under whose authority, with evidence that holds up afterwards. It is Kubernetes-native, installs from a public Helm chart, and runs inside a customer's own cluster.

Endpoint management platforms

Every MCP server starts as a file on a laptop. Magertron reads those files through the MDM an enterprise already runs — Jamf Pro, Microsoft Intune, Kandji — and matches what it finds to the governed registry.

  • A policy script and an extension attribute; no agent on the endpoint
  • Three postures set by the administrator: Observe, Advise, or Enforce at next check-in

Ships today as a script plus scheduler for Linux and macOS, with Ansible delivery; Jamf Pro and Intune packaging in progress. Any MDM that can run a signed script and report its output works the same way.
