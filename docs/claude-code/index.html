Magertron™ for Claude Code

Point Claude Code at your platform. Every tool call is authorized, metered and recorded with your name on it.

Install

npm install -g @anthropic-ai/claude-code

Needs Node 18 or later and Claude Code 2.1.202 or later.

User guide (PDF) Anthropic’s MCP docs

Get your config

  1. In the Developer Portal, click Add to IDE and choose Claude Code
  2. Save the file as .mcp.json at your project root

Browsers drop the leading dot, so rename mcp.json to .mcp.json.

Authenticate

export MCP_TOKEN="<your token>"

The file holds no credential, so it’s safe to commit. Your team gets the same servers without passing tokens around.

Connect

cd your-project
claude

Approve the servers when Claude Code asks, then check them with /mcp.

If it doesn’t work

Run claude mcp get <server>.

You seeIt means
Pending approvalRun claude in that folder to approve

A tool that disappeared usually changed and is waiting for re-approval.
